# TaskManager

Aplicación de gestión de tareas en JavaScript Vanilla (ES6+), con módulos nativos,
consumo de la API JSONPlaceholder y persistencia en localStorage.

## Cómo ejecutarla
Abrir la carpeta en un editor con servidor local (Phoenix Code Live Preview o Live Server)
y ejecutar `index.html`. Los módulos ES6 no funcionan con doble clic.
